MIT SERIEOVERBLIK - KOMPLET GITHUB PAGES PAKKE

Upload alle 8 filer fra ZIP-filen til roden af dit eksisterende Serieliste-repository:
index.html, app.js, pwa.js, sw.js, manifest.webmanifest, favicon.svg, icon-192.png, icon-512.png.

Behold Microsoft Entra redirect URI https://bsstaal.github.io/Serieliste/ hvis dette er din aktuelle GitHub Pages-adresse. Hvis adressen er anderledes, skal redirect i app.js og i Entra svare til den aktuelle adresse.

Microsoft-login og Excel/OneDrive kræver internet. PWA'en kan installeres på enheden, men data hentes fra OneDrive efter login. Lav en sikkerhedskopi af Excel inden redigering.
